# R2 private storage (P5 slice)

## Rules

1. Bucket **private** — no public ACL / public URL for documents.
2. Upload/download only via Worker (`/files/*`) after session + ownership checks.
3. Object keys **server-built only** — never accept client `objectKey`.
4. MIME allowlist + size caps (see `@pe-smkk/shared` `FILE_LIMITS` / `ALLOWED_MIME`).
5. Metadata in D1 `documents`; blob in R2 binding `DOCUMENTS`.

## Local

```bash
# wrangler.toml already binds DOCUMENTS (local sim)
npm run db:migrate:local
npm run dev:api
```

Upload example (after login cookie):

```bash
curl -b cookies.txt -F purpose=report_document -F reportId=REPORT_ID -F file=@./sample.pdf \
  http://localhost:8787/files/upload
```

## Production

Create bucket once:

```bash
npx wrangler r2 bucket create pe-smkk-documents
```

Align `database_id` / account in `wrangler.toml`; set secrets via dashboard.
